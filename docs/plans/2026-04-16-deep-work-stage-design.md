# Design: Stage 5 — Trabajo Activo (Deep Work / Integración)

**Date:** 2026-04-16  
**Status:** Approved

---

## Problem

The "Antes de irte, tres preguntas para el camino" section in stage-closure presented 3 reflection questions for the user to take home. This wasted the most therapeutically fertile moment in the session — the minutes immediately after receiving an interpretation — by deferring resolution to later rather than enabling it now.

## Solution

Add a new Stage 5 ("Integración / Trabajo Activo") between Interpretation (stage 4) and Closure (stage 6). The user picks one of 3 actionable work cards and has a brief focused dialogue (2–3 exchanges) with the AI therapist in resolutive mode. The synthesis feeds into the closure letter, making it richer and more specific.

---

## User Flow

```
Stage 4: Interpretación
        ↓
Stage 5: Integración (NEW)
  ① Load  — generate 3 WorkCards from reflection questions
  ② Select — user picks one card
  ③ Dialogue — 2–3 exchanges, AI in resolutive mode
  ④ Synthesis — AI closes: "Lo que veo en lo que exploraste..."
  ⑤ Advance — deepWork saved to session, go to stage 6
        ↓
Stage 6: Cierre (was stage 5)
  — "Antes de irte" section removed
  — closure letter enriched with deepWork.synthesis
```

---

## Work Cards

Each card converts a reflective question into an actionable work portal:

```typescript
interface WorkCard {
  id: string;
  title: string;       // "Explorar por qué evitas el conflicto" (verb in infinitive)
  subtitle: string;    // original reflection question, shown in italics
  openingLine: string; // first therapist line when user selects this card
}
```

Cards are generated by AI using the patient's full context (conflicts, framework, interpretation text). The AI transforms open contemplative questions into specific, directed entry points.

---

## Deep Work Dialogue

- **Max 3 therapist turns**, then automatic synthesis
- **Prompt difference from Stage 2**: AI already knows everything — no exploration, only resolution. Each question moves toward a concrete insight or micro-shift.
- **AI response format**: `{ done: boolean; response: string; synthesis?: string }`
- When `done: true`, `synthesis` contains a 2–3 sentence summary of what the user arrived at

## Design Principles

- **YAGNI**: No new concept beyond the conversation pattern already established in Stage 2
- **Emotional continuity**: Dialogue mode is consistent with the rest of the app
- **Brief by design**: 3-turn cap prevents fatigue after a full session
- **Feeds forward**: deepWork.synthesis enriches the closure letter — the two stages are causally linked
